# Lesson 24 – DC Motors

## 📘 Overview
In this lesson, I learned how to use a DC motor with a power supply module.

## 🔧 Components Used
- Arduino Uno R3 Board × 1
- M-M wires × 5
- L293D IC × 1
- Fan blade and 3-6v motor × 1
- Power Supply Module × 1
- 9V1A adapter × 1
